## 5. 資料抓取

```powershell
cd food_map_ccu_v1
$env:PYTHONPATH = "src"
$env:GOOGLE_MAPS_API_KEY = "你的金鑰"

# 建議先試跑（省 API）
python scripts/fetch_places_to_json.py `
  --lat 23.5615 --lon 120.4808 `
  --radius-m 8000 --grid 10 --max-pages 5 --target 1000 `
  --out data/places_cache.json

python scripts/enrich_food_groups.py data/places_cache.json
python scripts/stats_food_groups.py data/places_cache.json
```

| 風險 | 說明 |
|------|------|
| API 費用 | 8 km 面積約為宜大 1 km 的 **64 倍** |
| 飽和 | 實際 unique 店可能 500–1500 |
| 非美食 | 需 `food_group_overrides.json` 清理 |
